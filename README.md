# КиберЩит

Образовательная платформа о безопасности в интернете для детей и подростков.
Статический сайт (HTML/CSS/JS, иконки Lucide) на GitHub Pages. Базы данных и своего сервера нет.

Сайт: https://insomn1adevelopment.github.io/CyberShieldRework/

## Как это работает

- **Аккаунт** создаётся и хранится только в браузере пользователя (куки `cs_acc`, `cs_prog`, `cs_in`).
  На другом устройстве или после очистки кук его не будет. Пароль хранится в виде хэша SHA-256 и защищает
  только от случайного входа — у владельца браузера есть полный доступ к своим кукам.
- **КиберAI и помощник** отвечают через нейросеть Groq: сайт обращается к ней напрямую из браузера.
  Если ключ не задан или Groq недоступен, чат отвечает из встроенной базы (`AI_FALLBACK` в `static/data.js`).

## Запуск на своём компьютере

Нужен Python 3.7+ (python.org/downloads, при установке отметь «Add Python to PATH»). Двойной клик по `start.bat` или:
```
python -m http.server 8000 -d static
```
Открой **http://localhost:8000**. Остановить — `Ctrl+C`.

Файл `index.html` нельзя открывать двойным кликом: браузеры не сохраняют куки для `file://`, поэтому аккаунт работать не будет.

## Нейросеть (Groq)

1. На console.groq.com → API Keys создай ключ.
2. Впиши его в `static/app.js` → `CONFIG.groqKey` и опубликуй сайт.

Ключ виден любому посетителю в коде страницы — поставь лимиты в консоли Groq. Правила для ИИ (промпты) — `PROMPTS` в `static/app.js`.

## Публикация сайта

Содержимое папки `static/` лежит в ветке `gh-pages`, GitHub Pages публикует её автоматически.

## Что где лежит

- `static/index.html`, `style.css`, `app.js` — сайт, аккаунт в куках, режимы «Защитник» и «Хакер».
- `static/data.js` — учебный контент: вопросы, дела, законы, встроенные ответы КиберAI. Тексты законов сверены с pravo.by.
- `static/vendor/` — Lucide (загружается с сайта, без внешних CDN).
