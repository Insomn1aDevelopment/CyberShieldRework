# КиберЩит

Образовательная платформа о безопасности в интернете для детей и подростков.
Бэкенд — Python (только стандартная библиотека), база — SQLite, фронтенд — HTML/CSS/JS, Three.js, иконки Lucide.

## Запуск на своём компьютере

1. Установи **Python 3.10 или новее** — python.org/downloads (при установке отметь «Add Python to PATH»).
2. Открой папку проекта в терминале (PowerShell или командная строка).
3. Скопируй настройки:
   ```
   copy .env.example .env
   ```
4. Открой `.env` в блокноте и впиши хотя бы ключ AI (см. ниже). Без ключа сайт работает, но КиберAI отвечает из встроенной базы ответов.
5. Запусти сервер:
   ```
   python server.py
   ```
   или двойной клик по `start.bat`: окно консоли останется открытым, сервер останавливается через `Ctrl+C`.
6. Открой в браузере **http://localhost:8000**

Остановить сервер — `Ctrl+C` в окне терминала. База данных создаётся сама в файле `cybershield.db`.
Устанавливать ничего, кроме Python, не нужно.

## Настройки (.env)

| Параметр | Что это |
|---|---|
| `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` | Твой OpenAI-совместимый API для консультанта КиберAI и помощника в углу. Примеры адресов — в `.env.example` |
| `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET` | Ключи Cloudflare Turnstile («Я не робот» на регистрации и входе). Получить: dash.cloudflare.com → Turnstile → Add site → указать свой домен. Пока ключей нет, работают тестовые ключи Cloudflare: они пропускают всех, а на виджете написано «Только для тестирования» |
| `YOUTUBE_ID` | ID видео для плеера на главной. Из ссылки `https://www.youtube.com/watch?v=dQw4w9WgXcQ` нужно взять `dQw4w9WgXcQ` |
| `ADMIN_NICKS` | Никнеймы модераторов через запятую — они могут удалять любые записи в ленте |
| `TRUST_PROXY` | `1`, если сайт работает через прокси Cloudflare |

После изменения `.env` перезапусти сервер.

## Проверка

```
python test_server.py
```
Должно вывести `OK`.

## Публикация в интернете с защитой Cloudflare

1. Арендуй любой VPS (Ubuntu), установи Python 3.10+, скопируй папку проекта.
2. Запусти сервер так, чтобы он работал постоянно (например, через systemd или `screen`) за nginx/Caddy с HTTPS.
3. Добавь домен в Cloudflare и включи проксирование (оранжевое облако). Тогда Cloudflare защищает сайт от DDoS-атак и скрывает адрес сервера.
4. В `.env` укажи боевые ключи Turnstile для своего домена и `TRUST_PROXY=1`.

## Что где лежит

- `server.py` — API: регистрация и вход, прогресс и достижения, лента, AI, защита (Turnstile, лимиты запросов, фильтр личных данных и грубых слов, блокировка после 5 неверных паролей).
- `static/index.html`, `style.css`, `app.js` — сайт.
- `static/data.js` — весь учебный контент: вопросы, дела, законы. Тексты законов сверены с pravo.by.
- `static/scene.js` — 3D-щит на главной.
- `static/vendor/` — Three.js и Lucide (загружаются с нашего сервера, без внешних CDN).

## База данных

SQLite, схема обновляется автоматически при запуске (миграции через `pragma user_version`).
Таблицы: `users`, `sessions` (токены хранятся только в виде хэша), `user_stats`, `user_achievements`, `posts`, `likes`, `reports`.
Без аккаунта прогресс не сохраняется. С аккаунтом статистика и достижения хранятся на сервере и доступны с любого устройства.
