# КиберЩит

Образовательная платформа о безопасности в интернете для детей и подростков.
Статический сайт (HTML/CSS/JS, иконки Lucide) на GitHub Pages. Базы данных и своего сервера нет.

Сайт: https://insomn1adevelopment.github.io/CyberShieldRework/

## Как это работает

- **Аккаунт** создаётся и хранится только в браузере пользователя (куки `cs_acc`, `cs_prog`, `cs_in`).
  На другом устройстве или после очистки кук его не будет. Пароль хранится в виде хэша SHA-256 и защищает
  только от случайного входа — у владельца браузера есть полный доступ к своим кукам.
- **КиберAI и помощник** отвечают через нейросеть: сайт отправляет вопрос в Cloudflare Worker (папка `worker/`),
  а тот — в Groq. Ключ нейросети хранится в секретах Cloudflare и в браузер не попадает.
  Если Worker не настроен, перегружен или недоступен, чат отвечает из встроенной базы (`AI_FALLBACK` в `static/data.js`).

## Запуск на своём компьютере

Нужен Python 3.7+ (python.org/downloads, при установке отметь «Add Python to PATH»). Двойной клик по `start.bat` или:
```
python -m http.server 8000 -d static
```
Открой **http://localhost:8000**. Остановить — `Ctrl+C`.

Файл `index.html` нельзя открывать двойным кликом: браузеры не сохраняют куки для `file://`, поэтому аккаунт работать не будет.

## Нейросеть (Cloudflare Worker)

Нужны бесплатные аккаунты на cloudflare.com и console.groq.com, а также Node.js 18+.

1. На console.groq.com → API Keys создай ключ.
2. В терминале в папке проекта:
   ```
   cd worker
   npx wrangler@4 login
   npx wrangler@4 deploy
   npx wrangler@4 secret put AI_API_KEY
   ```
   `login` откроет браузер для входа в Cloudflare. После `deploy` появится адрес вида
   `https://cybershield-ai.<имя>.workers.dev`. На шаге `secret put` вставь ключ Groq.
3. Впиши этот адрес в `static/app.js` → `CONFIG.aiUrl` и опубликуй сайт.

Настройки — в `worker/wrangler.toml`:

| Параметр | Что это |
|---|---|
| `ALLOWED_ORIGINS` | Сайты, которым разрешено спрашивать нейросеть. Добавь свой домен, если переедешь с GitHub Pages |
| `AI_BASE_URL`, `AI_MODEL` | OpenAI-совместимый API и модель. По умолчанию Groq и `llama-3.3-70b-versatile` |
| `[[ratelimits]]` | Не больше 10 вопросов в минуту с одного IP |

Ошибки нейросети в реальном времени: `npx wrangler@4 tail` в папке `worker`.

## Проверка

```
node worker/test.mjs
```
Должно вывести `OK`.

## Публикация сайта

Содержимое папки `static/` лежит в ветке `gh-pages`, GitHub Pages публикует её автоматически.

## Что где лежит

- `static/index.html`, `style.css`, `app.js` — сайт, аккаунт в куках, режимы «Защитник» и «Хакер».
- `static/data.js` — учебный контент: вопросы, дела, законы, встроенные ответы КиберAI. Тексты законов сверены с pravo.by.
- `static/vendor/` — Lucide (загружается с сайта, без внешних CDN).
- `worker/` — посредник к нейросети: правила для ИИ (промпты), проверка сайта-источника, лимит запросов.
