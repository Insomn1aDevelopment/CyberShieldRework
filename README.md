# КиберЩит

Образовательная платформа о безопасности в интернете для детей и подростков.
Фронтенд — HTML/CSS/JS, иконки Lucide. Базы данных нет: аккаунт и прогресс хранятся в куках браузера.
Бэкенд необязателен — Python (только стандартная библиотека), нужен лишь для подключения нейросети к КиберAI.

Сайт: https://insomn1adevelopment.github.io/CyberShieldRework/

## Как это работает

- **Аккаунт** создаётся и хранится только в браузере пользователя (куки `cs_acc`, `cs_prog`, `cs_in`).
  На другом устройстве или после очистки кук его не будет. Пароль хранится в виде хэша SHA-256 и защищает
  только от случайного входа — у владельца браузера есть полный доступ к своим кукам.
- **КиберAI и помощник** без сервера (на GitHub Pages) отвечают из встроенной базы ответов (`AI_FALLBACK` в `static/data.js`).
  С запущенным `server.py` и ключом AI отвечает нейросеть.

## Запуск на своём компьютере

1. Установи **Python 3.10 или новее** — python.org/downloads (при установке отметь «Add Python to PATH»).
2. Открой папку проекта в терминале и запусти:
   ```
   python server.py
   ```
   или двойной клик по `start.bat`. Остановить — `Ctrl+C`.
3. Открой в браузере **http://localhost:8000**

Файл `index.html` нельзя открывать двойным кликом: браузеры не сохраняют куки для `file://`, поэтому аккаунт работать не будет.

## Настройки (.env)

Создай файл `.env` рядом с `server.py`:

| Параметр | Что это |
|---|---|
| `AI_BASE_URL`, `AI_API_KEY`, `AI_MODEL` | OpenAI-совместимый API для КиберAI. По умолчанию — Groq (`https://api.groq.com/openai/v1`, модель `llama-3.3-70b-versatile`) |
| `YOUTUBE_ID` | ID видео для плеера на главной. Из ссылки `https://www.youtube.com/watch?v=dQw4w9WgXcQ` нужно взять `dQw4w9WgXcQ` |
| `TRUST_PROXY` | `1`, если сервер работает за прокси Cloudflare |
| `PORT` | Порт сервера, по умолчанию `8000` |

После изменения `.env` перезапусти сервер. Ключ AI хранится только на сервере и в браузер не попадает.

## Проверка

```
python test_server.py
```
Должно вывести `OK`.

## Публикация

- **GitHub Pages:** содержимое папки `static/` лежит в ветке `gh-pages`. Всё, кроме нейросети, работает.
- **С нейросетью:** запусти `server.py` на любом VPS за nginx/Caddy с HTTPS, по желанию — через прокси Cloudflare с `TRUST_PROXY=1`.

## Что где лежит

- `server.py` — раздаёт сайт и передаёт вопросы нейросети (`/api/ai`, лимит 20 запросов за 10 минут с одного IP).
- `static/index.html`, `style.css`, `app.js` — сайт, аккаунт в куках.
- `static/data.js` — весь учебный контент: вопросы, дела, законы, встроенные ответы КиберAI. Тексты законов сверены с pravo.by.
- `static/vendor/` — Lucide (загружается с нашего сервера, без внешних CDN).
